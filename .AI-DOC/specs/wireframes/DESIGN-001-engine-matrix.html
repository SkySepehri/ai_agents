Implementation Notes
  • EngineMatrix renders a plain HTML <table> with proper <thead> and scope="col" on th elements -- not antd Table. This gives precise control over severity chip cell layout.
  • Severity count cells that are 0 show a dash (—) not a "0" chip. Non-zero counts show a clickable chip with color + shape + count.
  • DrillDownPanel: antd Collapse rendered as an inline <tr> below the selected row. One panel open at a time -- clicking a new cell collapses the previous one.
  • Sub-score color thresholds: 75-100 = sub-score-critical (#DC2626), 50-74 = sub-score-high (#E17036), 25-49 = sub-score-medium (#FFDC00), 0-24 = sub-score-low (#52C41A).
  • ADUpsellBanner: spans all 7 columns (colspan=7). Background gradient matches existing BreachLikelihood card gradient. "Learn more" button links to the Dela upsell URL. Must NEVER show a numeric sub-score for AD when not integrated.
  • ADTeaserBanner: rendered as a div above the table, not as a table row. Uses yellow (#FFDC00) color to signal informational (not danger, not upsell).
  • Engine order (no Threat Detection): IH, PH, II, M365, AD (conditional). Remove "Threat Detection" from EngineOrderMapping in constants.ts and from ENGINE_ORDER in MSSP ReportsPage.tsx.
