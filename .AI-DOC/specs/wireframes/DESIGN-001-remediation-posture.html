Implementation Notes
  • Remediation items: antd Collapse with accordion prop. Each panel is a RemediationItem component. Collapse header contains rank badge + severity chip + title + delta chip + expand icon.
  • Risk delta chips: negative numbers always. Format: "-N pts" (string). Color: severity of the item's severity field (Critical=red, High=orange, Medium=yellow). Do NOT show positive deltas.
  • Paths severed badges: path IDs from the API (e.g., "path-001"). If more than 3 paths are severed, show "path-001, path-002 +N more".
  • Posture view layout: 3-column grid on desktop (min-width 1024px). On tablet (768px-1023px): 1-column stacked. On mobile: 1-column.
  • NIST CSF function labels: "Govern", "Identify", "Protect", "Detect", "Respond" -- use these exact labels from the API response keys.
  • Essential Eight ML dots: 4 positions (ML0, ML1, ML2, ML3). Position 0 is always the leftmost dot. Fill dots up to currentMaturityLevel. Draw target ring at targetMaturityLevel position. If target == current, the filled dot also gets a ring.
  • Essential Eight strategies with assessed=false: show strategy name + "Not assessed by BLA" text. Do NOT render dots for unassessed strategies.
  • antd Progress component: use strokeColor prop to set bar color based on coveragePercent. Thresholds: >=70% -> #52C41A, 40-69% -> #FFDC00, <40% -> #DC2626.
  • Posture data is fetched on mount (usePosture hook), not on toggle click. Toggle is pure CSS visibility swap.
