Implementation Notes
  • NodeDetailPanel and EdgeDetailPanel: use antd Drawer with placement="right", mask={false}, width={380}. Both render into the graph container's DOM subtree.
  • Only one panel open at a time. If a second node/edge is clicked while a panel is open, the panel content updates without close/re-open animation.
  • Clicking the graph background (SVG canvas, not a node/edge) clears selection and closes panel.
  • BlastRadiusOverlay: absolutely positioned within the graph container div. CSS transform translateY(100%) initially, animates to translateY(0) on show. Not mounted until first triggered (lazy mount). Unmounted on close for performance.
  • All inline SVG icons for resource types -- no external CDN references. Use simple geometric shapes or Unicode characters. In production implementation, use small inline SVG paths.
  • Focus management: when a panel opens, focus moves to the panel's close button. Escape key listener is on the panel container.
  • The Tier-0 target node (e.g., Global Administrator directory role) has fixText=null in the API response. The NodeDetailPanel must show "No remediation available for target nodes." for this case.
