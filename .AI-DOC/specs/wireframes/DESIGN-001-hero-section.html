Implementation Notes
  • ScoreRing.tsx uses ECharts gauge type. Replace the existing GaugeChart.tsx (Chart.js half-circle, no animation).
  • The ring is a full circle (360 degrees), not a half-circle. Inner text shows numeric score + risk label.
  • ECharts count-up animation: use animationDuration and animationType: "linear" with a data update from 0 to score on mount.
  • KPI alarm condition logic: ttgaHops > 0 shows alarm; leakedAdminPasswords > 0 shows alarm; standingGlobalAdmins > 2 shows alarm; pathsToTakeover > 0 shows alarm. adminsWithMfa is always neutral (informational).
  • Card gradient: linear-gradient(-170deg, #3B3544 0%, #151517 50%, #26222E 100%) -- matches existing BreachLikelihood.tsx gradientBoxLeftStyle.
  • Skeleton uses antd Skeleton.Input and Skeleton.Avatar, or the shimmer CSS class shown above.
  • When identities API returns 404: render existing "Assessing your Entra ID..." message. When 500: render error state with retry button.
